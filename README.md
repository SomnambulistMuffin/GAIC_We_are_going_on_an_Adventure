# GAIC_We_are_going_on_an_Adventure
a text based adventure rpg where you make a decision on how the game progresses

the game uses qvac LLAMA_3_2_1B_INST_Q4_0 AI model to run a prompt that generates unique 6 turn based adventures.
you have the option to choose the genre then navigate through 3 choices to progress your campaign.
this is a game when you're waiting in a queue, on a commute, or just bored in between debugging and package downloads regardless of how it ends I hope you have fun!

can be run offline without internet connection.

**SET UP**
copy the folder and files into your directory
install node.js version 22.21.1
in the terminal run the following commands
    npm install @qvac/sdk
    npm install

once the packages have installed in the folder you can just run the script in the terminal:
  node game.js
